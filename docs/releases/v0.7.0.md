# DevTrail v0.7.0

## Highlights

- A calmer daily flow in the menu bar: create or open today’s devlog, refresh GitHub activity, summarize merged PRs, and backfill past days.
- A local-first link library: save normal web URLs without AI, keep page metadata, and organize links by clear developer-focused rules.
- One capture field for YouTube and normal web links. A successful save clears the field for the next link.
- PR summaries now distinguish a GitHub activity row from an actual AI summary, preventing false success messages and duplicates.

## Who should try this release

Developers on macOS who use Obsidian and want a single local flow for daily work, project context, and references.

## Upgrade / installation

New install:

```bash
curl -fsSL https://raw.githubusercontent.com/p-changki/devtrail/main/install.sh | bash
devtrail init
```

Existing install:

```bash
devtrail update --apply
devtrail app install
```

To organize existing uncategorized web links, preview first and then apply:

```bash
devtrail capture web --organize
devtrail capture web --organize --apply
```

## Known limitations

- macOS is the supported platform.
- Web metadata quality varies by site; JavaScript-only or blocked pages may save the URL with limited metadata.
- AI features are optional and depend on the user’s configured local provider.
- DevTrail Command Center is prepared for an Obsidian Community Plugin release, but is not registered in the Community Plugin directory yet.
