# 개발일지

> 이 폴더만 봅니다. DevTrail 이 만들었고 `devtrail augment --refresh-hubs` 로 갱신됩니다.

## 최근

```dataview
TABLE WITHOUT ID
  file.link AS "노트",
  dateformat(file.mtime, "yyyy-MM-dd") AS "수정"
FROM "notes/개발/개발일지"
WHERE file.name != "_index"
SORT file.mtime DESC
LIMIT 15
```

## 재방문할 때가 됐다

> ℹ️ `review_at` 커버리지가 33.4% 입니다 — 값이 있는 노트는 예정일로, 없는 노트는 마지막 수정일로 봅니다.

```dataview
LIST
FROM "notes/개발/개발일지"
WHERE file.name != "_index"
  AND ((review_at AND review_at <= date(today))
  OR (!review_at AND file.mtime <= date(today) - dur(90 days)))
SORT file.mtime ASC
LIMIT 15
```

## 미완성

```dataview
TABLE WITHOUT ID file.link AS "노트", file.size AS "크기"
FROM "notes/개발/개발일지"
WHERE file.name != "_index" AND (status = "draft")
SORT file.size ASC
LIMIT 10
```

## 연결이 없다

```dataview
LIST
FROM "notes/개발/개발일지"
```
