# 개발일지

> 이 폴더만 봅니다. DevTrail 이 만들었고 `devtrail augment --refresh-hubs` 로 갱신됩니다.

## 최근

```dataview
TABLE WITHOUT ID
  file.link AS "노트",
  dateformat(file.mtime, "yyyy-MM-dd") AS "수정"
FROM "notes/개발/개발일지"
WHERE file.name != "_index"
SORT file.mtime DESC
LIMIT 15
```

## 재방문할 때가 됐다

```dataview
LIST
FROM "notes/개발/개발일지"
WHERE file.name != "_index"
  AND (review_at AND review_at <= date(today))
SORT review_at ASC
LIMIT 15
```

## 미완성

> ℹ️ `status` 커버리지가 10.0% 입니다 — 분량이 적은 노트도 함께 봅니다.

```dataview
TABLE WITHOUT ID file.link AS "노트", file.size AS "크기"
FROM "notes/개발/개발일지"
WHERE file.name != "_index" AND (status = "draft" OR (!status AND file.size < 500))
SORT file.size ASC
LIMIT 10
```

## 연결이 없다

```dataview
LIST
FROM "notes/개발/개발일지"
WHERE file.name != "_index"
  AND length(file.outlinks) = 0 AND length(file.inlinks) = 0
SORT file.ctime DESC
LIMIT 10
```
