# ⌨️ Hotkeys

> Keys already in use **are avoided** at install time.
> To see what you actually got: Settings → Hotkeys, search `DevTrail` or `Templater`.

## Creating notes

| Key | What | Where it goes |
|---|---|---|
| `⌘⇧D` | Devlog | Devlog folder |
| `⌘⇧M` | Dev note | **Pick an area** → Frontend/Backend/… |
| `⌘⇧N` | Reference card | Zettel |
| `⌘⇧I` | Idea | Ideas |
| `⌘⇧R` | Retro | Pick weekly/monthly/quarterly/project |
| `⌘⇧P` | New project | Project + 8-step docs skeleton |
| `⌘N` | Pick a template | Choose from the list |

## DevTrail commands

| Key | What |
|---|---|
| `⌘⇧G` | Pull today's GitHub issues/PRs into the devlog |
| `⌘⇧S` | Summarize merged PRs in plain language with AI |
| `⌘⇧B` | Backfill a specific date |

You can also search `DevTrail` in the command palette (`⌘P`).

## Obsidian basics

| Key | What |
|---|---|
| `⌘O` | Quick open |
| `⌘⇧F` | Search everything |
| `⌘E` | Toggle edit/preview |
| `⌘,` | Settings |

## If a hotkey does nothing

1. Restart Obsidian (always required right after install)
2. Settings → Hotkeys, check for a conflict
3. Run `devtrail obsidian` again
