# 📘 Getting started

New to Obsidian? That's fine. **You will never create a folder by hand.**

## The idea, in one line

> **Never think about where a note goes.**
> Press a hotkey, pick from the list, and it lands in the right place.

## A day

| When | What | How |
|---|---|---|
| Morning | Top 3 for today | `⌘⇧D` devlog |
| Working | Something you learned | `⌘⇧M` dev note → pick an area |
| Working | Something you got stuck on | New note in the Troubleshooting folder |
| Working | An idea | `⌘⇧I` |
| Before logging off | Pull in GitHub activity | `⌘⇧G` |
| Friday | Weekly review | New note in the Weekly folder |

Step by step: [[Daily check-in]]

## Your first week

- [ ] Write a devlog with `⌘⇧D` on at least 3 days
- [ ] Make one dev note with `⌘⇧M` — watch where it lands
- [ ] Bookmark [[Dashboard]] in the sidebar
- [ ] Create one weekly review on Friday

**Don't try to do it perfectly.** Writing roughly but continuously beats
writing well for three days and stopping.

## When you get stuck

- Can't find a folder → use the buttons on [[Dashboard]]
- Hotkeys don't work → restart Obsidian, then `devtrail doctor`
- A note seems to have vanished → it was probably filed by its tag.
  Search for it with `⌘O`
