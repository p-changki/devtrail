# 🗂 폴더와 태그

## 태그가 폴더를 정합니다

노트에 `#type/idea` 를 붙이면 **아이디어 폴더로 자동 이동**합니다.
템플릿이 태그를 알아서 붙이므로, 보통은 신경 쓸 필요가 없습니다.

## 태그 5종

| 네임스페이스 | 뜻 | 예 |
|---|---|---|
| `#type/*` | 노트 유형 **(필수)** | `type/devlog` · `type/dev-note/frontend` |
| `#project/*` | 프로젝트 귀속 | `project/my-app` |
| `#주제/*` | 주제 분류 (권장) | `주제/rag` · `주제/nextjs` |
| `#상태/*` | 숙성도 (카드노트 전용) | `상태/seedling` → `budding` → `evergreen` |
| `#area/*` | 영역 | `area/dev` · `area/resource` |

## 숙성도 3단계

카드노트에만 씁니다. **아무거나 카드노트로 올리면 쓰레기통이 됩니다.**

```
seedling   막 옮겨 적음
budding    내 언어로 다시 씀
evergreen  다른 노트와 연결됨
```

승격 조건 3가지 — 셋 다 되어야 올립니다:

- [ ] 내 언어로 재작성했다
- [ ] `#주제/` 태그를 붙였다
- [ ] 관련 노트를 2개 이상 링크했다

## 자료실 흐름

```
00_Inbox     막 담은 것 (2일 안에 처리)
10_원본      첨부파일 (자동)
20_카드노트  승격된 것 · MOC
30_아카이브  보관 (검색·이동 대상 아님)
```

## 자동으로 안 옮기는 폴더

프로젝트 · 학습 · 아카이브 · 템플릿은 **자동 이동에서 뺐습니다.**
안에서 직접 구조를 관리하는 곳이라 자동 이동이 방해가 됩니다.

## frontmatter

| 필드 | 뜻 |
|---|---|
| `type` | 노트 유형 (필수) |
| `status` | `draft` · `active` · `inbox` · `done` |
| `created` · `updated` | 날짜 (Linter가 자동 갱신) |
| `review_at` | **재방문 예정일** — 폴더 허브가 이걸 보고 "밀렸다"고 알려줍니다 |

> `review_at` 을 비워두면 허브가 마지막 수정일로 근사합니다.
> 채울수록 정확해집니다.
