# 📘 시작하기

Obsidian이 처음이어도 됩니다. **폴더를 직접 만들 일은 없습니다.**

## 이 볼트의 원리 한 줄

> 노트를 만들 때 **어디에 넣을지 고민하지 않는다.**
> 단축키를 누르면 선택창이 뜨고, 고르면 제자리에 만들어집니다.

## 하루 흐름

| 때 | 무엇 | 어떻게 |
|---|---|---|
| 아침 | 오늘 할 것 3개 | `⌘⇧D` 개발일지 |
| 작업 중 | 배운 것 | `⌘⇧M` 개발메모 → 영역 선택 |
| 작업 중 | 막힌 것 | 트러블슈팅 폴더에서 새 노트 |
| 작업 중 | 떠오른 것 | `⌘⇧I` 아이디어 |
| 퇴근 전 | GitHub 활동 넣기 | `⌘⇧G` |
| 금요일 | 주간리뷰 | 주간리뷰 폴더에서 새 노트 |

자세한 순서: [[일일 체크인]]

## 처음 일주일에 할 것

- [ ] `⌘⇧D` 로 개발일지를 3일 이상 쓴다
- [ ] `⌘⇧M` 으로 개발메모를 하나 만들어본다 — 어느 폴더로 가는지 확인
- [ ] [[대시보드]] 를 사이드바에 북마크한다
- [ ] 금요일에 주간리뷰를 한 번 만든다

**완벽하게 쓰려 하지 마세요.** 3일 쓰고 멈추는 것보다 대충이라도 계속 쌓는 게 낫습니다.

## 막히면

- 폴더가 안 보인다 → [[대시보드]] 의 버튼으로 이동
- 단축키가 안 먹는다 → Obsidian 재시작, 그래도 안 되면 `devtrail doctor`
- 노트가 사라진 것 같다 → 태그를 보고 자동으로 옮겨졌을 수 있습니다. 검색(`⌘O`)으로 찾으세요
