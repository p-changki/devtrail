# ⌨️ 단축키

> 설치 시점에 **이미 쓰이는 키는 피해서** 배정됩니다.
> 실제 배정은 설정 → 단축키에서 `DevTrail` 또는 `Templater` 로 검색하세요.

## 노트 만들기

| 키 | 무엇 | 어디로 |
|---|---|---|
| `⌘⇧D` | 개발일지 | 개발일지 폴더 |
| `⌘⇧M` | 개발메모 | **영역 선택** → Frontend/Backend/… |
| `⌘⇧N` | 자료카드 | 카드노트 |
| `⌘⇧I` | 아이디어 | 아이디어 |
| `⌘⇧R` | 회고 | 주간/월간/분기/프로젝트 선택 |
| `⌘⇧P` | 프로젝트 생성 | 프로젝트 + docs 골격 8단계 |
| `⌘⇧W` | 워크로그 | 프로젝트 선택 → 작업 하나 = 폴더 하나 |
| `⌘N` | 템플릿 선택 | 목록에서 고르기 |

## DevTrail 명령

| 키 | 무엇 |
|---|---|
| `⌘⇧G` | 오늘 GitHub 이슈/PR 을 일지에 넣기 |
| `⌘⇧S` | 머지된 PR 을 AI로 쉬운말 요약 |
| `⌘⇧B` | 날짜 지정 백필 |

명령 팔레트(`⌘P`)에서 `DevTrail` 로 검색해도 됩니다.

## Obsidian 기본

| 키 | 무엇 |
|---|---|
| `⌘O` | 빠른 열기 |
| `⌘⇧F` | 전체 검색 |
| `⌘E` | 편집/미리보기 전환 |
| `⌘,` | 설정 |

## 단축키가 안 먹으면

1. Obsidian 재시작 (설치 직후엔 반드시)
2. 설정 → 단축키에서 충돌 확인
3. `devtrail obsidian` 을 다시 실행
