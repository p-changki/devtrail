# 🗺 SUBJECTS — 무엇을 어떤 순서로

> 일차 폴더(`day01`, `day02` …)는 그대로 두고,
> 이 문서는 **"순서를 어떻게 엮을지"** 만 정합니다.

## 왜 과목을 나누나

한 가지만 파면 지칩니다. 성격이 다른 걸 **병렬로** 돌리면
하나가 막혀도 다른 데서 진도가 나갑니다.

세 갈래를 권합니다 — 서로 이어집니다:

```
A 만들기        직접 코드를 쓰는 힘
B 돌아가게 하기  환경 · 도구 · 배포
C 적용하기      실제 코드에 붙여보기
```
