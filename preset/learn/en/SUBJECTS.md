# 🗺 SUBJECTS — what to learn, in what order

> The day folders (`day01`, `day02` …) stay as they are.
> This document only decides **how to thread them together**.

## Why split into subjects

Digging at one thing wears you out. Running things of a different nature
**in parallel** means that when one blocks you, another still moves.

Three tracks work well — they feed each other:

```
A Building        the ability to write the code yourself
B Making it run   environments · tooling · deploys
C Applying it     putting it into real code
```
