# 일지 → 주간 → 월간 롤업

**원본 볼트에서 월간리뷰가 0개였던 이유가 이 마찰입니다.**
일지는 매일 쌓이는데 그걸 위로 굴려 올리는 사람이 없었습니다.

## 🔑 경로

```bash
devtrail path devlog    devtrail path weekly    devtrail path monthly
```

## 무엇을 하나

| 대상 | 읽는 것 | 쓰는 곳 |
|---|---|---|
| 주간 | 그 주의 개발일지 5~7개 | 주간리뷰의 빈 섹션 |
| 월간 | 그 달의 주간리뷰 4~5개 | 월간리뷰의 빈 섹션 |

**Dataview 가 이미 목록은 뽑아줍니다.** 이 스킬이 하는 건 목록이 아니라
**요약과 패턴 찾기**입니다.

## 절차

### 1. 대상 확인

노트가 이미 있으면 **빈 섹션만 채웁니다.** 사용자가 쓴 내용을 덮어쓰지 마세요.
없으면 Obsidian에서 템플릿으로 만들라고 안내합니다.

### 2. 읽기

해당 기간의 일지를 읽습니다. **자동 집계 섹션은 건너뜁니다** —
Dataview 코드블록과 「오늘 만든 노트」 같은 것은 내용이 아닙니다.

### 3. 채울 것

주간리뷰:
- **메인 테마** — 이번 주를 한 단어로
- **새로 배운 것** — 일지의 「오늘 배운 것」을 모아 중복 제거
- **재방문 가치 있는 노트 3개** — 실제 링크로
- **미완료** — 일지에서 체크 안 된 것

월간리뷰:
- **배운 것 TOP 3** — 주간의 반복 주제
- **성취** — 머지된 PR·완료한 프로젝트
- **개선할 점** — 반복해서 밀린 것

### 4. 규칙

- **없는 것을 지어내지 않습니다.** 일지가 3일치뿐이면 "3일치 기준"이라고 밝힙니다
- **한 줄 요약은 사용자가 씁니다.** 「이번 주 한 줄」은 비워둡니다 — 남이 쓴 회고는 회고가 아닙니다
- 공백일이 있으면 지적합니다

## 결과 보고

```
주간리뷰 2026-W34 · 일지 5개 읽음
  메인 테마: 인증 리팩터
  새로 배운 것 4개 · 미완료 2개
  ⚠️ 공백일 2일 (08-19, 08-20)
  ✍️ 「이번 주 한 줄」은 직접 채워주세요
```
