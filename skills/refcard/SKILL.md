# 레퍼런스 카드

라이브러리나 도구를 쓰고 나서 **"이거 뭐였더라"** 를 없애는 노트입니다.

## 🔑 경로

```bash
devtrail path library    # 라이브러리
devtrail path tool       # 개발 도구·사이트
```

## 파일명 규칙 — 이게 핵심입니다

```
TanStack Query - 서버 상태 관리
SkeletonUI - 로딩 상태, 그라데이션
npm trends - 패키지 다운로드 추이 비교
```

**`이름 - 한 줄 설명`** 입니다.
목록만 훑어도 뭐였는지 알게 하는 것이 목적입니다. 검색이 필요 없어집니다.

## 무엇을 채우나

| 섹션 | 쓸 것 |
|---|---|
| 한 줄 요약 | 파일명의 설명과 같아도 됩니다 |
| **언제 쓰는가** | 가장 중요합니다 — 어떤 상황에서 이걸 떠올려야 하나 |
| 설치 | 실제로 되는 명령 |
| 핵심 사용법 | **최소 동작 코드** — 문서를 복사하지 말고 |
| 트러블슈팅 | 내가 겪은 것만 |
| 레퍼런스 | 공식 문서 · GitHub |

## 규칙

- **공식 문서를 옮겨 적지 마세요.** 그건 링크로 충분합니다
- 「언제 쓰는가」와 「내가 겪은 트러블」이 이 노트의 값어치입니다
- 안 써본 것은 만들지 않습니다 — 위시리스트는 아이디어 폴더로

## 절차

1. 라이브러리인지 도구인지 판별 → 폴더 결정
2. 같은 이름이 이미 있는지 확인 (있으면 갱신)
3. 대화 맥락에서 「언제 쓰는가」와 트러블을 뽑아 채웁니다
4. 모르는 항목은 **비워둡니다.** 지어내지 마세요

## 결과 보고

```
✅ TanStack Query - 서버 상태 관리 → 라이브러리/
   언제 쓰는가 · 핵심 사용법 채움
   ⚠️ 트러블슈팅은 비워뒀습니다 (겪은 것이 없음)
```
