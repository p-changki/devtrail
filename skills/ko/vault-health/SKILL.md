# 볼트 위생 점검

## 🔑 먼저 이걸 돌리세요

```bash
devtrail scan --json
```

폴더·태그·frontmatter 커버리지·충돌이 전부 나옵니다.
**직접 세지 말고 이 결과를 쓰세요.**

## 점검 항목

### 1. Inbox 적체

```bash
find "$(devtrail path inbox)" -name '*.md' -mtime +14 -not -name '_index.md'
```

14일 넘은 것이 있으면 `/devtrail-promote` 를 권합니다.
20개가 넘으면 **경고**합니다 — 그 이상은 사람이 감당 못 합니다.

### 2. 고아 노트

링크가 들어오지도 나가지도 않는 노트. 다시 안 읽힙니다.

Dataview 로 세는 것이 정확합니다. 허브의 「연결이 없다」 블록이 이미 봅니다.

### 3. 깨진 링크

```bash
grep -rho '\[\[[^]|]*' "$(devtrail path --rel . 2>/dev/null || echo .)" 2>/dev/null
```

`[[...]]` 대상 파일이 실제로 있는지 확인합니다.
**자동으로 고치지 마세요** — 오타인지 의도적 미래 링크인지 알 수 없습니다.

### 4. 메타데이터 누락

`devtrail scan` 의 `fields` 를 봅니다.
**키만 있고 값이 빈 것**을 따로 셉니다 — 이 둘을 합치면 커버리지를 과대평가합니다.

커버리지가 낮으면 허브 쿼리가 근사치로 동작한다고 알립니다.

### 5. 공백일

개발일지가 며칠 비었는지. **매일 하라고 다그치지 마세요.**
끊긴 걸 알려주고 다시 시작하기 쉽게 하는 게 목적입니다.


## 하지 말 것

- 자동으로 고치기 — 보고만 합니다
- 점수 매기기 — 숫자로 압박하면 볼트를 안 열게 됩니다
- 노트 삭제 제안 (고아 노트도 나중에 연결될 수 있습니다)
